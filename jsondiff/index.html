Compare Two JSON Inputs Online

Compare two structured inputs by path and review added, removed and changed values. Both sides are parsed locally in your browser, and the inputs can be JSON, YAML, XML, CSV, TSV or JSONL.

How to Compare JSON

  1. Paste or import the left and right inputs.
  2. Choose Auto-detect or select the input format for each side.
  3. Review the summary and the change list, then copy or download the diff.

What the Diff Shows

Objects are compared structurally, so key order does not create differences. Arrays are compared by index. Added, removed and changed values are shown with their JSONPath.

A changed value displays its before and after values. Large differences are limited and marked as truncated.

Input Formats and Limits

Each side can use JSON, YAML, XML, CSV, TSV or JSONL. CSV and XML conversions may be lossy, so compare the parsed JSON structures rather than the original source text.

The comparison runs locally. Very large inputs require clicking Compare instead of waiting for automatic comparison.

Frequently Asked Questions

Does JSON key order matter?

No. Objects are compared structurally, so the same keys in a different order are considered equal.

How are arrays compared?

Arrays are compared by index. An item inserted at the beginning can therefore appear as many changes in the following positions.

Is my JSON uploaded?

No. Both inputs are parsed and compared in your browser.
