Convert and Merge Intel HEX, SREC and BIN

Convert Intel HEX and Motorola S-record files to raw BIN, generate HEX or SREC from BIN, merge images by address, fill gaps, crop ranges and export individual segments locally.

Convert Firmware Formats

  1. Paste HEX or SREC text, or drop .hex, .srec and .bin files.
  2. Enter a base address before adding a BIN file; BIN has no address metadata.
  3. Choose BIN, Intel HEX or Motorola SREC as the output and select Generate.
  4. Download the result or copy the generated text.

Merge and Fill

Files are merged by absolute address. The default policy rejects overlapping data; you can keep the first value or let later files overwrite it.

BIN output starts at the lowest address and fills gaps with the selected byte, 0xFF by default. Use the start and end fields to restrict the exported range.

Export Segments

The merged image is split into continuous address ranges. Each row can be downloaded as BIN, HEX or SREC without changing the other segments.

Intel HEX and SREC output preserve gaps instead of inserting fill bytes; record length and address width can be adjusted for the target toolchain.

Frequently Asked Questions

Why does a BIN file need a base address?

A raw BIN file contains no address information. Provide the flash or memory address where the first byte belongs, such as 0x08000000.

What happens when images overlap?

By default the converter stops and reports the conflict. Keep-first or last-wins can resolve overlaps when you know which image is authoritative.

Are file checksums verified?

Yes. Every Intel HEX and S-record line is checked for a valid checksum and record length before conversion.

How large can the output be?

BIN output spans are capped at 64 MiB. Use the crop fields or segment export to avoid expanding large address gaps.
