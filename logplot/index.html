Plot Curves from Serial Logs, CSV, TSV or JSON

Paste plain-text serial output, a delimited table or JSON. The page detects the likely X axis and numeric data columns, then draws a line chart as you type. Parsing and drawing happen locally in your browser.

How to Plot Your Data

  1. Paste serial logs, CSV/TSV rows or JSON into the input area, or load one of the samples.
  2. The page detects the format, treats the first row as a header when it is not numeric, and builds a table of columns.
  3. A time-like or increasing numeric column becomes the X axis; other numeric columns with changing values become curves.
  4. Use the "Data columns" chips to show or hide curves, and the "X axis" dropdown to switch axes.
  5. Drag across the chart to zoom, double-click to reset, then export PNG or CSV when needed.

Supported Input Formats

Key-value logs: one or more key: value or key=value pairs per line. Records start at a time field; fields written before the time field, such as sys clock, are attached to the following record.

Delimited text: comma, tab, semicolon or pipe, with or without a header row. Quoted cells are supported.

JSON: an array of objects, arrays of rows, column arrays, or newline-delimited JSON objects. Nested objects are flattened with dot notation.

time,temperature(C),humidity(%)
2026-08-28T11:17:59Z,25.1,48
2026-08-28T11:18:00Z,25.4,47

Automatic Detection Rules

A column is treated as time when most values parse as a date-time, time-of-day or epoch timestamp in seconds, milliseconds or nanoseconds.

If no time column exists, the first increasing numeric column such as a clock or step counter is used, otherwise the row index becomes the X axis.

Numeric columns with changing values are plotted by default. Constant columns and monotonic counters are left unchecked but can be enabled.

sys clock:19481 status:2
current time: 2026/08/28 11:17:59
sample voltage: 3126 mV

Units and Limits

Units are read from headers such as temperature(C) or from values such as 3126 mV. They are labels only; values are not converted between units.

All curves share one Y axis. Log times without a time zone are treated as UTC. A time-of-day axis cannot detect midnight rollover, so backwards points are skipped and reported.

Privacy

The paste is never uploaded; it is kept in local storage so a refresh does not lose it. The website may still load analytics scripts.

Frequently Asked Questions

Why is my chart empty?

No numeric columns were detected, or the X axis has no valid values. Check that the data has at least one numeric column and a recognizable time or counter column.

Can I plot other fields such as current?

Yes. Any numeric column can be toggled as a curve, and a time-like or increasing column can be selected as the X axis.

Can it read the serial port directly?

Not yet. Copy the output from a terminal such as the Web Serial Terminal and paste it here.
