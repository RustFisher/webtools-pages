Validate JSON with JSON Schema Online

Check JSON data against a JSON Schema and review validation errors by instance path. Schemas and data are parsed and validated locally in your browser.

How to Validate JSON

  1. Paste or import a JSON Schema on the left and the JSON data on the right.
  2. Keep Auto-detect or choose the input format; JSON, YAML, XML, CSV, TSV and JSONL are accepted for the instance.
  3. Select Validate, or wait for the automatic check, then review each error path and keyword.

Supported Keywords

Draft 2020-12 is supported, including type, required, properties, additionalProperties, items, prefixItems, enum, const, anyOf, oneOf, allOf and $ref. Formats such as date-time, email, uri, ipv4 and uuid are checked when present.

Most Draft-07 schemas also validate because unknown keywords are ignored. Keywords whose semantics changed between drafts, such as dependencies or exclusiveMinimum, may behave differently.

Reading Validation Errors

Each error shows its JSONPath, the failing keyword and the schema location. Click the path to copy it, or copy the whole error list as JSON.

The on-screen list is capped to keep the page responsive; copying errors includes the full list.

Frequently Asked Questions

Is my schema or data uploaded?

No. Parsing and validation run in your browser with a bundled JSON Schema validator.

Which JSON Schema drafts are supported?

Draft 2020-12 is fully supported. Most Draft-07 schemas work as well, but draft-specific keyword semantics may differ.

Why does an empty JSONPath appear?

An empty path means the error applies to the whole instance, such as a missing required field or a disallowed extra property.
