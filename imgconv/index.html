FAQ

Are my images uploaded?

No. Image decoding, resizing, encoding and Base64 generation all run locally in your browser.

Why does a transparent background turn white after converting to JPEG?

JPEG has no alpha channel, so transparent areas are filled with the selected background color, white by default. Choose PNG or WebP to keep transparency.

Why is the output image larger than the original?

Re-encoding changes the compression. A high quality setting, an enlarged size, or converting from an already heavily compressed format can make the file larger.

How much does Base64 increase the size?

Base64 uses four characters for every three bytes, so the text is about 1.33 times the size of the original binary data.

Choosing an Output Format

PNG is lossless and keeps an alpha channel, which suits icons, screenshots and images that need transparency. JPEG is lossy and widely compatible; it has no alpha channel, so transparent areas are filled with the selected background. WebP can be lossy or effectively lossless depending on the quality setting and usually produces a smaller file than JPEG or PNG at a similar appearance.

Re-encoding always creates a new file. Converting a heavily compressed JPEG to PNG does not restore lost detail, and it usually makes the file much larger. Converting a PNG with transparency to JPEG requires filling the background.

Resizing and Quality

Original keeps the decoded dimensions. Percent scales both axes by the same factor. Fixed width or fixed height preserves the aspect ratio and calculates the other side automatically. The page reports the target dimensions before conversion.

For JPEG and WebP, lower quality values reduce file size and remove more detail. PNG ignores the quality setting because it is lossless. Output is limited to 16 million pixels to stay within common browser canvas limits.

Base64 and Data URLs

Base64 encodes the converted bytes as text. A Data URL prefixes the Base64 payload with its MIME type, such as data:image/webp;base64,..., so it can be used directly in an img src or CSS url(). Raw Base64 omits that prefix.

Base64 is encoding, not compression: the text is about 1.33 times the size of the binary image. Very large images also produce very large text strings, which can be cumbersome to edit or paste.

Frequently Asked Questions

Are my images uploaded?

No. The page decodes and encodes images with browser APIs and does not send them to a processing server. The website still loads third-party analytics and advertising scripts.

Why does JPEG turn transparency white?

JPEG has no alpha channel. Transparent areas are composited onto the selected background, which defaults to white. Use PNG or WebP when transparency must be preserved.

Why is the new file larger than the original?

The original may already be heavily compressed, the output quality may be high, or the output dimensions may be larger. Try a lower quality, smaller dimensions, or a different format.

Does converting to PNG improve quality?

No. PNG preserves the pixels it receives, but it cannot restore detail that a previous lossy encoding removed. Start from the highest-quality source available.
