Calculate File and Text Hashes Online

Compute MD5, SHA-1, SHA-256, SHA-512, CRC32 and HMAC for text or files. Files are read in chunks and hashed locally in your browser.

Hash Text or a File

  1. Choose Text or File and enter the text or drop a file.
  2. Select one or more algorithms; MD5 and SHA-1 are marked as insecure for authentication.
  3. For HMAC, choose the hash algorithm and enter the key as text or hex.
  4. Select Calculate or recompute and copy, download or compare the result.

Supported Algorithms

SHA-256 and SHA-512 are the usual choices for file integrity, while MD5 and SHA-1 remain useful for legacy compatibility and non-security checksums.

CRC32 is a fast error-detection checksum, not a cryptographic hash. The calculator uses the standard IEEE polynomial and shows eight hex digits.

HMAC combines a hash with a secret key and supports SHA-1, SHA-256 and SHA-512 here. Keys stay in memory and are never uploaded or stored.

Verify a Downloaded File

Paste the checksum published by the vendor into the expected-hash field. The page normalizes spaces, prefixes such as SHA256: and letter case, then reports which algorithm matches.

Files are read with the browser file stream API, so multi-gigabyte files are hashed in chunks without being uploaded or loaded all at once.

Frequently Asked Questions

Is my file uploaded?

No. The file is read in chunks and hashed with a bundled WebAssembly implementation in your browser.

Which hash should I use?

Use SHA-256 or SHA-512 for integrity and signatures. Avoid MD5 and SHA-1 for new security work; CRC32 is only for error detection.

Why does the CRC32 result look different from another tool?

This page uses the standard IEEE 802.3 CRC32 polynomial and displays the checksum in uppercase hex. Tools that show a decimal value or a different polynomial will differ.

Can I hash a very large file?

Yes. Files are streamed in chunks, and you can cancel a running hash at any time. Available memory and disk speed determine the practical limit.
